# 对冲再平衡时按同一规则重选 put，而不是只调张数

spec 写的是：净 delta 超过阈值时「调整 put 张数使净 delta 回到 0」，put 只在到期前 5 个交易日换到新的次月平值合约。按字面实现时，换月之间行权价和月份都不变。ETF 大涨后，持有的 put 会变成深度虚值；临近到期时，按网格向下取一档的 put 也会偏虚值。这两种情况下 delta 都趋近 0，按 delta 算出的张数就会失控。2016–2026 的真实数据回测中，2016-07 一次要买 600 多万张，资金耗尽后对冲失效，净值跌掉 90%。

因此，每次再平衡都按建仓、换月时的同一条规则重新选 put：平值（行权价网格上不高于 ETF 收盘价的最近一档）、次月（当日所在月份的下一个月）。选出的合约就是持有的 put 时只调张数，否则平掉旧 put、买入新 put。换月规则（持有的 put 到期前 5 个交易日）保持不变。

## Consequences

- 对冲腿的期限始终在 3–8 周左右，单笔张数稳定在几十到几百张（真实回测最多 548 张）。
- 再平衡可能连带换合约，换手比只调张数高，期权费用随之增加。2016–2026 期权费用约 32 万元。
- 行权价间距较大（5–10 元档为 0.25）时，「向下取一档」的 put 仍可能虚值 4% 左右，低波动时期 delta 偏小、张数偏多，这是 spec 选择规则带来的，保留不改。
