# 01: 搭骨架：双均线端到端跑通

**What to build:** 研究者装好依赖后，用一条命令（`backtest ma_cross`）就能对一只 A 股跑完双均线回测，并得到绩效指标、净值图和成交表。数据从 baostock 获取并缓存到本地，第二次运行不需要联网。股票先只支持基础的买卖和佣金，A 股的完整撮合规则在 02 和 03 中补充。同时搭好唯一的测试接缝：用手工构造的 bar 组成 DataFeed 注入回测引擎，测试只断言回测结果。

包含内容：venv 和 requirements、`git init` 和 `.gitignore`（忽略虚拟环境、数据缓存、`.scratch`）；DataFeed 接口与 baostock 适配器（不复权价、后复权价、复权因子、停牌状态、ST 状态、交易日历）及 Parquet 缓存；统一的 Portfolio 账户（ADR-0001）；按交易日推进的回测引擎，闲置现金按年化 1.5% 计息；股票品种的基础版本；策略接口；双均线策略（MA5/MA20，信号日收盘产生信号、成交日开盘成交，满仓买入，股数先简单取整）；绩效指标（年化收益、最大回撤、夏普、胜率、换手率、总费用）和与买入持有基准的比较；命令行入口。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 一条命令完成 venv 创建和依赖安装，git 仓库已初始化，`.gitignore` 已生效
- [ ] `backtest ma_cross` 能用真实数据跑完 sh.600519 在 2016-01-01 至最新的回测，输出指标、净值图文件，以及成交和每日状态的表格文件
- [ ] 第二次运行命中本地缓存，断网也能完成回测
- [ ] 回测只在交易日历中的交易日推进
- [ ] 股票信号在信号日收盘产生、在成交日开盘成交（有测试覆盖）
- [ ] 现金计息有测试覆盖：空仓 N 天后的净值等于按年化利率计算的结果
- [ ] 测试接缝可用：pytest 用手工构造的 DataFeed 驱动引擎，只断言成交记录、持仓、现金、净值
- [ ] 一个默认跳过的联网冒烟测试，用来验证 baostock 适配器
