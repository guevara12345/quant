# 06: 滚 IC + put delta 中性

**What to build:** 研究者运行 `backtest roll_ic`，就能看到“滚 IC 加平值次月 500ETF put 动态对冲到 delta 中性”在 2016 年至今的表现，并据此判断贴水收益能不能覆盖对冲成本。

包含内容：在 04 的滚 IC 策略上叠加 put 对冲。每日收盘计算组合净 delta（期货与 put 的 delta 都按名义本金折算）；建仓时以及净 delta 的绝对值超过 IC 名义本金的 10% 时，调整 put 张数使净 delta 回到 0（阈值可配置，设为 0 时每日再平衡）；put 选平值（按行权价网格向下取最近一档）、次月合约，在到期前 5 个交易日换到新的次月合约。报告输出三条净值曲线（本策略、纯滚 IC、中证 500）、每日净 delta，以及收益拆解（贴水收敛、put 成本、交易费用、现金利息）。报告需要标注“期权价格为模型价”，并区分 500ETF 期权上市（2022-09）前后两个时段。

**Blocked by:** 04, 05

**Status:** done

- [x] 测试：建仓后组合净 delta 接近 0，put 张数取整造成的误差在一张以内
- [x] 测试：净 delta 超过阈值时触发再平衡，未超过时不触发；阈值设为 0 时每日再平衡
- [x] 测试：put 在到期前 5 个交易日换到新的次月平值合约
- [x] 测试：IC 展期当天对冲关系保持不变，展期后组合净 delta 仍在阈值内
- [x] 测试：收益拆解各项之和等于总盈亏
- [x] `backtest roll_ic` 能用真实数据跑完 2016-01-01 至最新，输出三条净值曲线、每日净 delta 和收益拆解
- [x] 报告中标注“期权价格为模型价”，并按 2022-09 前后分段给出指标

## 实现说明

- 再平衡时按建仓、换月的同一规则（当日的次月、平值）重选 put，选出的就是持有的 put 才只调张数（ADR-0004）。字面的「只调张数」在 put 偏虚值时 delta 趋近 0：真实数据中 2016-07 一次要买 600 多万张，资金耗尽后对冲失效。
- 收益拆解四项：贴水收敛（IC 盈亏中基差变化的部分）、指数涨跌与 put（put 盈亏 + IC 随中证 500 涨跌的盈亏，即 put 的对冲成本）、交易费用、现金利息；之和等于总盈亏。
- 2016-01-01 至 2026-10-23 真实数据：本策略年化 4.38%、最大回撤 12.6%，总盈亏 185.3 万元（对冲成本 −102.4 万、费用 −32.5 万）；纯滚 IC 总盈亏 323.9 万元。2022-09-19 后本策略年化 0.88%。
